# Architecture decisions

| # | Decision |
|---|---|
| [0001](0001-native-kotlin-with-a-plain-kotlin-core.md) | The app is native Kotlin and Compose over a plain Kotlin core |
| [0002](0002-a-note-is-one-memo.md) | A note is one memo, with its title and color written into the Markdown |
| [0003](0003-the-device-is-the-source-of-truth.md) | The device is the source of truth, and a conflict keeps both versions |
| [0004](0004-the-version-is-written-in-the-build-file-and-a-tag-marks-it.md) | The version is written in the app's build file, and a tag marks each release |
| [0005](0005-browser-sign-in-comes-back-to-the-phone-over-loopback.md) | Browser sign-in comes back to the phone over loopback, and the app keeps an access token of its own |
| [0006](0006-a-note-in-the-trash-is-an-archived-memo.md) | A note in the trash is an archived memo until its days there are up |
| [0007](0007-tags-are-read-from-the-text-the-way-memos-reads-them.md) | Tags are read from the note's text the way memos reads them |
| [0008](0008-a-notes-place-on-the-board-is-its-memos-create-time.md) | A note's place on the board is its memo's create time |
| [0009](0009-a-recording-is-an-audio-attachment-of-its-notes-memo.md) | A recording is an audio attachment of its note's memo |
