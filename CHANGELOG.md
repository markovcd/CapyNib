# Changelog

## Unreleased

### Features

- Keep-style notes: colored cards, titles, pinning, archive and search.
- A trash that keeps deleted notes for a week, or as many days as you set.
- Checklists with items you can tick.
- Tags: write `#tag` in a note to see it on the card and narrow the board to it.
- Long press to pick several notes and pin, color, archive or delete them together.
- Drag a note to move it; its place syncs, and the memos web app lists notes in the same order.
- Swipe a note left to archive it, right to pin it, with Undo for archive and delete. Either way unpins a pinned note.
- In the archive, swipe right to unarchive and left to delete; in the trash, swipe right to restore and left to delete forever, which asks first.
- In the trash, long press to restore or delete forever several notes at once.
- Quick capture: a home screen widget, launcher shortcuts, a Quick Settings tile and Share to Capynib each open a new note ready to type.
- Sync with a memos server as you type, working offline until the server is back.
- `capynib` command line for the same notes and sync.
- Sign in with the browser, such as with Google, on memos servers that offer it.
- Check server tries every call sync makes against your memos server and names any that fail.
- Its own icon, a calm teal-grey look, a readable note palette and the Figtree typeface.
